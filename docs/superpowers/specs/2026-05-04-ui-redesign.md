# Tomato App UI 重构设计

**日期**: 2026-05-04
**状态**: 待审核

## 概述

将 Tomato 番茄钟应用从单列 Tab 布局重构为三列布局，并增加底部状态栏，使计时状态在所有页面可见。

## 目标

1. 提升任务管理效率 - 任务树始终可见
2. 保持计时状态可见 - 切换 Tab 不丢失状态感知
3. 为后续功能（任务笔记）预留扩展空间

## Phase 1: 布局重构（本次实现）

### 1.1 整体布局结构

```
┌─────────────────────────────────────────────────────────┐
│ [拖拽区域 - 标题栏]                                      │
├──────┬─────────────────┬─────────────────────────────────┤
│ Tab  │                 │                                 │
│ 导航 │ 任务树          │ 内容区                          │
│ 60px │ 240px           │ flex                            │
│      │                 │                                 │
│ 🍅   │ 📁 工作 (3)     │ 任务详情 / 计时器 / 统计 / 设置 │
│ 📋   │   ├ 任务1       │                                 │
│ 📊   │   ├ 任务2       │                                 │
│ ⚙️   │ 📁 学习 (2)     │                                 │
│      │                 │                                 │
├──────┴─────────────────┴─────────────────────────────────┤
│ Tomato v0.1.0        📊 今日 3 个番茄    🍅 24:35 专注中  │
└─────────────────────────────────────────────────────────┘
```

### 1.2 组件结构

```
App
└── AppShell (重构)

    ├── MainContent

    │   └── ContentPanel
    │       ├── TimerPage - 番茄计时（居中）

    │       └── SettingsPage - 设置（居中）
```

### 1.3 窗口尺寸调整

### 1.4 Tab 页面布局规则

| Tab | 任务树 | 内容区 |
|-----|--------|--------|
| 番茄 | 隐藏 | 居中显示计时器 |
| 任务 | 显示 | 任务详情（标题 + 笔记） |
| 统计 | 隐藏 | 居中显示统计卡片 |
| 设置 | 隐藏 | 居中显示设置表单 |

### 1.5 任务树交互

1. **分组折叠**
   - 点击分组标题折叠/展开
   - 折叠状态保存到本地存储
   - 折叠图标：▼（展开）/ ▶（折叠）

2. **任务选中**
   - 单击任务 → 右侧显示任务详情
   - 选中任务高亮（红色左边框 + 浅红背景）
   - 当前计时的任务特殊标记（🍅 图标）

3. **分组操作**
   - 悬停显示操作按钮
   - 更多菜单：重命名、删除

4. **任务操作**
   - 悬停显示：开始、编辑、删除
   - 复选框切换完成状态

### 1.6 底部状态栏

```
┌─────────────────────────────────────────────────────────┐
│ Tomato v0.1.0  │  📊 今日 3 个番茄  │  🍅 24:35 专注中  │
└─────────────────────────────────────────────────────────┘
```

**组成部分：**
- 左侧：版本号
- 中间：今日番茄数
- 右侧：计时状态（图标 + 时间 + 状态文字）

**状态显示：**
| 状态 | 图标颜色 | 文字 |
|------|----------|------|
| idle | 灰色 | 就绪 |
| working | 红色 | 专注中 MM:SS |
| paused | 橙色 | 已暂停 MM:SS |
| breaking | 绿色 | 休息中 MM:SS |
| long-break | 绿色 | 长休息 MM:SS |

### 1.7 暗色模式适配

- 状态栏背景：`bg-gray-100 dark:bg-gray-800`
- 任务树背景：`bg-gray-50 dark:bg-gray-900`
- 选中任务：`bg-red-50 dark:bg-red-900/20`
