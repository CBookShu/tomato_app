# E2E 测试平台设计文档

**日期**: 2026-05-06
**状态**: 待审核

## 概述

通过 Playwright 测试真实 Electron 应用，建立端到端的用户流程测试机制。

## 目标

1. **测试真实 Electron 应用**，而非 Vite dev server
2. **覆盖核心用户流程**，而非孤立组件
3. **建立可维护的选择器策略**，避免测试脆弱
4. **支持快速迭代**，短时番茄钟配置

---

## 一、技术架构

### 1.1 测试层级

真实 Electron 应用测试，使用 SQLite 持久化存储。

### 1.2 关键配置

| 配置项 | 值 | 说明 |
|--------|-----|------|
| 番茄时长 | 5 秒 | 测试环境 |
| 短休息 | 3 秒 | 测试环境 |
| 长休息 | 5 秒 | 测试环境 |
| 测试超时 | 60 秒 | Electron 启动较慢 |
